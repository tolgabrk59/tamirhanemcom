## Dispatch Protokolü

1. Kullanıcı isteğini al
2. Anahtar kelimeleri analiz et
3. **DOĞRUDAN** Agent tool ile çağır (sorma, açıklama yapma)
4. Sonucu kullanıcıya sun

### Çoklu Agent Senaryoları

Bazı durumlar birden fazla agent gerektirir:

```
MVP → engineering-rapid-prototyper + engineering-frontend-developer + engineering-backend-architect

Marketing Kampanyası → marketing-content-creator + marketing-social-media-strategist + marketing-growth-hacker

Enterprise Feature → project-manager-senior + engineering-senior-developer + testing-reality-checker

Oyun → game-designer + level-designer + (engine-specific agent)
```
